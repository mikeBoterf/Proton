## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The crypto tests backing the retracted verdict in TASK-9 were inadequate. Verified against docs/elytra-diagnostics/bcrypt_inplace_test.c:

1. It encrypts AND decrypts through the same Wine backend (lines 43, 51), proving self-consistency rather than equivalence to Windows. An implementation wrong in a symmetric way passes cleanly. This is what made "bit-for-bit correct" unsupportable.
2. Both calls pass dwFlags = 0, so the padded path — the one that reportedly fails — is never exercised.
3. main() returns 0 unconditionally and discards every test_mode return value (line 72), so the exit code carries no signal.

Fix by generating fixtures with an implementation outside Wine (openssl), exercising BCRYPT_BLOCK_PADDING, and making exit codes meaningful.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Fixtures are now generated by openssl via fixtures/generate-fixtures.sh — verified reproducible (regenerating yields byte-identical files). This is the first evidence for Wine's padded in-place decrypt that does not round-trip through Wine itself; the valid fixture decrypts correctly (status=0, len=47), matching Windows.

bcrypt_inplace_test.c: added test_fixture() covering valid and malformed PKCS7 against the external fixtures, including the IV-advance check; main() now accumulates failures and returns non-zero; output is written to bcrypt-inplace.txt because Proton's launcher does not surface console output.

padding-matrix.c imported from the Windows control package and built (needs -D__USE_MINGW_ANSI_STDIO=0 with -nostdlib, otherwise __mingw_fprintf is undefined).

UNPLANNED FIND: the baseline run surfaced `[AES-ECB 1MB] encrypt fail 0xc000000d`. That is a defect in the test, not in Wine — it passed an IV for ECB, which both Wine and Windows reject with STATUS_INVALID_PARAMETER. It had been failing silently for the entire investigation because main() returned 0 unconditionally. Fixed by passing NULL/0 for ECB. This is a concrete instance of the hardcoded exit code concealing a real defect.

Note for reproduction: the prefix must live under $HOME. steam-run mounts /tmp as a fresh tmpfs, so a prefix under /tmp is invisible inside the sandbox.

Still open: an exact-size (55,275,056 byte) padded fixture. The matrix uses 48-byte cases.
